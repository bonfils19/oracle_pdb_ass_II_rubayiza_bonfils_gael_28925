# scenario

By completing this assignment, you will demonstrate practical understanding of: Oracle Multitenant Architecture Creation and deletion of Pluggable Databases (PDBs) User creation and management inside a PDB Usage of Oracle Enterprise Manager (OEM) Professional technical documentation using GitHub

# Overview of Tasks
This repository contains the practical implementation and evidence for Assignment II in **Database Development with PL/SQL (INSY 8311)**. The project covers:
1. **Task 1:** Creation of a permanent Pluggable Database (PDB) and user account creation.
2. **Task 2:** Creation and complete deletion of a temporary PDB.
3. **Task 3:** Setup and verification of Oracle Enterprise Manager (OEM) / database administration console.
4. **Task 4:** Professional technical documentation and repository structuring.

# Oracle Environment Used
* **Database Edition:** Oracle Database Express Edition (XE) / 26c
* **Administration Tool:** Oracle SQL Developer
* **Operating System:** Windows 10
* **Connection Profile:** `sys_as_sysdba` (SYSDBA Privileges)
